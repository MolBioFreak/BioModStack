## Variant: Decision first

### Design stance
Put scientific acceptance and the selected candidate in front of the operator before detailed provenance.

### Key choices
- Layout: candidate rail, large viewer, selected-candidate inspector.
- Typography: readable sans-serif with compact metric labels.
- Color: mint acceptance state, cyan source geometry, dark slate chrome.
- Interaction: candidate selection, source overlay toggle, provenance drawer, artifact actions.

### Trade-offs
- Strong at: fast triage and a clear first viewport.
- Weak at: detailed multi-candidate comparison needs a second interaction.

### Best for
- Reviewing a batch and choosing one candidate for the next stage.
