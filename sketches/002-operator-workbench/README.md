## Variant: Operator workbench

### Design stance
Treat the result as a dense instrument panel for repeated technical review.

### Key choices
- Layout: three-column candidate list, structure canvas, inspector.
- Typography: monospace labels and compact tables for high information density.
- Color: restrained blue navigation with green, amber, and red state values.
- Interaction: candidate rows, source/candidate layer switches, tabs for validation, artifacts, and provenance.

### Trade-offs
- Strong at: power-user scanning and direct access to technical evidence.
- Weak at: lower visual warmth and less room for explanatory copy.

### Best for
- Operators comparing many generated candidates during one work session.
