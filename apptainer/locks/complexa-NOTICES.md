## External constraint and qualification limits

CCP4 `sc` is **not bundled**. No executable was found in the inspected existing image, PATH or host installation/tool directories. No registration or restricted license was accepted. If the selected Complexa task requests native binder shape-complementarity, provide an authorized CCP4 installation (exact version and executable/library/data byte manifest), with permission for the intended container/worker distribution. Official source: https://www.ccp4.ac.uk/download/index.php ; program: https://www.ccp4.ac.uk/html/sc.html ; terms: https://www.ccp4.ac.uk/ccp4-licence-and-conditions-2/ . This is an unresolved external requirement, not a new runtime refusal gate or a substitute score.

CPU import/CLI, single-sequence MSA and tiny clustering checks do not establish model inference, checkpoint loading, novelty-database completeness, relaxation or GPU/remote qualification. The candidate remains private; canonical image/activation is unchanged. La's existing ESMFold/ProteinMPNN evaluator is separate and is not changed by this image.
