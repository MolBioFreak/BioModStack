## Contract closure

Two earlier Phase N0 candidates were rejected by independent specification and quality review. This superseding candidate addresses the complete reported blocker set:

1. Dataset rows own exact receipt kinds, adapter IDs, roles, and compatibility rules. Current-head ONT state is excluded from immutable Dataset membership. The immutable ONT member path uses the observed-generation adapter only.
2. The result-manifest adapter freezes every accepted schema-present and schemaless version case.
3. Scheduled records bind existing source symbols for preparation, typed submission, entrypoint resolution, and command materialization.
4. ONT batch defaults and incompatibilities match the pinned compiler contract. Unsupported or unclassified settings keep their capabilities non-plannable.
5. Every parameter property records its native key, units, precision, scientific meaning, applicability, incompatibilities, reproducibility effect, UI control, persisted representation, default policy, and supported runtime range.
6. The NGS-owned outer Domain v2 schema freezes both normative discriminator values. Mandatory payload dispatch validates `ngs_molbio` against its registered closed payload schema. `protein_in_silico` fails closed until the Protein owner publishes its separately owned closed payload and constraint registries.
7. Scientific criterion and evidence wrappers use schema-discriminated branches with resolvable payload references.
8. Connector-event validation dispatches by the exact registered event type through its digest-bound payload schema, performs closed payload validation, and verifies the RFC 8785 payload digest.
9. Custom semantic uniqueness keywords are mandatory validator rules. Duplicate criterion IDs, evidence requirement IDs, group IDs, member identities, and ordinals fail validation.
10. The loader validates every registry against its registered schema, resolves every `$ref`, checks all byte bindings, enforces complete parameter partitions, verifies Dataset-role intersections, and resolves every non-null adapter owner to matching `adapter_id`, effective `adapter_version`, and `entity_kind`.
11. The baseline pin is non-circular. It verifies immutable baseline Git blobs without requiring the generated package commit to equal its parent.
12. Process-lifetime caching is absent. Every public authority access revalidates the current package, schemas, registries, and immutable baseline authority blobs.
13. Domain-operation execution remains `partial` when the Project schema uses immutable revisions while the native route consumes raw objects or sequences and no revision materializer exists.
