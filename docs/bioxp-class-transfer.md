# Positioned class-selected Transfer

`transfer.inputs` accepts the existing source/destination reference-well lists, four-head plunger channels, volume, position flags and nullable lift heights. Add `liquid` (the published pinned class/Water selector) and `recipe` (explicit native phase options) to select segmented lowering. The compiler never falls back to the old single-stroke transfer when a selector is present.

The transfer supplies single mode, channels and target liquid volume. Corrected displacement, aspiration speed, air volumes and ordered segment speeds may resolve from the exact class context. Explicit aspiration speed remains requested. Remove legacy `dispense_speed` explicitly: it cannot replace independent class segment speeds. Provide missing recipe choices—timeout, aspiration delay, leading/trailing air speeds or explicit absence, final-empty choice, final-empty positioning and multi=null. No manufacturer gap is replaced with invented science.

One `pipette_manual_physical` action with `operation=cavro_liquid_recipe` is emitted per head-reference pair. It contains real source move/lower/lift and destination move/lower/lift instructions around the recipe. Only the robot's `compile_liquid_recipe` expands liquid phases. Automatic tip policy runs on logical transfers before pairs become native actions; it never ejects between aspiration and its segments. All pair action IDs are retained in the effective-setting ledger. Additional explicitly authored recipe motions retain their phase order.

Raw inputs and omitted/null distinctions remain in snapshots. Stable labware IDs belong to planning/metadata, not device addressing. Signed channel geometry remains an explicit pinned labware-profile assumption. Neither an authored profile nor a planned head reference is calibration/readback.

Simulation keeps known commanded displacement separate from unknown liquid and air composition. Unknown endpoints do not become known zero effects. Partial reported effects mark the unreported remainder unknown. Recipe phase effect metadata uses named phases and segment indices, **not native child IDs**; partial segment displacement does not certify the logical target delivered. Native child identity and application outcomes remain owned by the native producer.

The native schema asset is exported from combined e58d3e5 under its offline guard. Start/cutoff speed mappings, barcode modes, thermal fan/paired ramps and pierce plate/pattern restrictions are represented. Park, RGB LED and SS shapes use the native-close published interface; their final source revision/registration remain explicitly unpinned until that lane commits. SS is a source no-op, not a physical seal actuator. Original-ADP host clot/air classification remains an unresolved scientific/source dependency.
