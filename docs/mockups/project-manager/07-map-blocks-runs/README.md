## Variant: Map, Blocks, and Runs

### Design stance
Preserve Research Map as the base layout, then add the selected elements from Experiment Canvas and Lab Notebook.

### Key choices
- Base layout: Project tree, central relationship map, and selected-node inspector from Research Map.
- Map segmentation: boxed Global Experiment and Domain Experiment regions from Experiment Canvas.
- Run presentation: compact run rows and actual replica detail from Lab Notebook.
- Add-to interaction: one reusable verified-record attachment modal.

### Best for
- The corrected primary Project Manager implementation candidate.
