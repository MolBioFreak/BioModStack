## Variant: Lab Notebook

### Design stance
Present each Global Experiment as an ELN-lite notebook chapter with inline Domain Experiment sections, records, decisions, and evidence.

### Key choices
- Layout: notebook index, full-width chapter record, and decision margin.
- Primary action: read and update the Project in scientific order.
- Add-to interaction: compact command-palette form.
- Scale behavior: chapter navigation and collapsed Domain Experiment sections.

### Trade-offs
- Strong at: chronological scientific context and low-friction documentation.
- Weak at: visual comparison across many concurrent workstreams.

### Best for
- An ELN-lite workflow where work organization and decision context must stay together.
