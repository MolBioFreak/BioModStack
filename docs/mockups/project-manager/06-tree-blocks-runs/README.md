## Variant: Project Tree, Experiment Blocks, and Runs

### Design stance
Combine the selected strengths from the second mockup round into one daily Project workspace.

### Key choices
- Project navigation: persistent hierarchical tree from Research Map.
- Main organization: large Domain Experiment blocks from Experiment Canvas.
- Run presentation: compact rows and inline expanded subruns from Lab Notebook.
- Relationship graph: secondary Project view rather than the default screen.
- Add-to interaction: one reusable verified-record attachment modal.

### Trade-offs
- Strong at: daily operation, hierarchy, run inspection, and cross-domain organization.
- Weak at: showing the complete relationship graph at the same time as run details.

### Best for
- The primary Project Manager implementation candidate.
