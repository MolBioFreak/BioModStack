## Variant: Research Map

### Design stance
Treat Project organization as an explicit relationship map that shows Project, Global Experiment, Domain Experiment, result, evidence, and dataset connections.

### Key choices
- Layout: hierarchy tree, visual map, and selected-node inspector.
- Primary action: select a node and inspect or reopen its canonical source.
- Add-to interaction: attachment modal launched from the current node or global prompt.
- Scale behavior: filterable and zoomable graph canvas.

### Trade-offs
- Strong at: provenance, lineage, and cross-domain relationships.
- Weak at: dense routine record editing.

### Best for
- Projects where understanding relationships is the central need.
