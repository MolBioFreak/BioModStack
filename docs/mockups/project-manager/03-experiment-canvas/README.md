## Variant: Experiment Canvas

### Design stance
Show one Project as a set of horizontal Global Experiment tracks, with Domain Experiments and attached work arranged left to right.

### Key choices
- Layout: scientific tracks rather than a Project list or dashboard.
- Primary action: scan one Project, then expand an Experiment track.
- Add-to interaction: reusable right-side attachment drawer.
- Scale behavior: horizontal lane scrolling within each experiment.

### Trade-offs
- Strong at: seeing cross-domain work within each scientific objective.
- Weak at: comparing many Projects at once.

### Best for
- Daily work inside one active Project.
