## What is approved

A real geometry workspace, focused RFD3 / Sequence design / Prediction / Run sections, primary settings before meaningfully grouped expert controls, and a cohort-first Results page with exact candidate inspection as drilldown. Reuse the current BMS themes, section/panel/run primitives, acquisition tools, native settings and shared result workbench. Section changes are navigation within one retained draft, not prerequisite steps.

The preview's representative fields do not set the coverage denominator. Applicable native fields still require typed controls, end-to-end transport and saved/readback parity. Preserve existing scientific defaults, Auto/Skip behavior, profile-fixed values and the current predictor roster. Do not copy engineering explanation into production cards or interpret the mockup's populated values as new defaults.

## Screen index

The identifiers below are the prototype's original print/capture manifest, not production URL contracts.

1. `geometry`: Geometry workspace.
2. `upload`: Upload and scale.
3. `generation`: RFD3 generation.
4. `proteinmpnn`: ProteinMPNN settings.
5. `fampnn`: FA-MPNN settings.
6. `caliby`: Caliby settings.
7. `prediction`: Structure prediction.
8. `run`: Run configuration.
9. `results`: Results overview.
10. `candidate`: Candidate inspection.
11. `recovery`: Read failure and recovery.

Open `prototype.html` directly in a browser. It needs no server or installation. Switch sections and designers, edit illustrative fields, toggle the theme, turn the sequence stage off/on, and open/return from candidate inspection. Browser printing assembles the full screen booklet. Local prototype drafts use an isolated browser key.

Buttons for upload, launch, scientific export or application save show a prototype notice only. The prototype submits no Jobs, provisions no workers, and changes no BMS state. Source names, numbers and mesh/structure drawings are illustrative, not native execution or Mol* evidence. Optional peer confidence and geometry scores must retain their real native meanings in implementation; never manufacture a missing scientific measurement to match a drawing.
