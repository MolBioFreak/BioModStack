## Proposed producer-to-F contract (not yet installed)

Apply `apptainer/bindcraft2-producer.patch` to the exact pinned upstream source during immutable image build. Patch applies cleanly via `git apply --check` on that checkout. No scientific rank/filter/acceptance logic changes:

- Each **claimed, deduplicated recipe** gets `1_Trajectories/!_BMS_Attempts/<design>.json`, with `schema_version=1`, `design` (native trajectory stem), `trajectory` (native claim number), `recipe_hash` (native, incomplete science identity), complete `effective_settings` **after autotune and desperation**, and sampled `drawn`. Canonical JSON excludes trailing newline when calculating SHA-256; sidecar ends in newline. A claim discarded as duplicate has no sidecar. An interrupted run may have a sidecar without a trajectory row. F must not use sidecar count as claimed count. The native campaign progress store remains accounting authority.
- Native trajectory CSV adds `bms_attempt_sha256`. F joins the row's exact `design` to the sidecar filename, validates the canonical sidecar digest against the column, and compares recipe hash and claim number. The attempt sidecar is immutable provenance, not an acceptance record. A trajectory-only or zero-yield run can have no scored/retained rows.
- For each retained sequence, accepted CSV and native mmCIF structure metadata both add `bms_scored_candidate` = `ValidatedBinder.candidate_number` (1-based scored draw) and `bms_attempt_sha256`. Join its `<trajectory>_seqN` retained identity to `<trajectory>_candidate<bms_scored_candidate>` in `2_Refolded` CSV; **never** infer this association from `seqN` order. Target-state CIF documents with the same retained identity and different state suffixes remain separate documents. Native rank may reorder further; use exact design identity rather than row position.
- The scored candidate CSV itself is unchanged. F must verify join cardinality, missing artifacts, and contradictions explicitly; a failed hook or absent sidecar is an incomplete provenance state, not license for ordinal reconstruction. BMS must persist an immutable full request digest independently from native recipe hash; same-folder resume is disabled until immutable identity and complete native state are qualified. Do not return only ranked rows: native hidden counters, sweep state, trajectory/refold/accepted/failed artifacts and sidecars belong to the return closure.

**Known gap:** this slice does not enforce native per-attempt sidecar-to-CIF integrity at production runtime, or prove a real native campaign. The patch is proposed for F's parser contract and G's image/return closure; it is not an installed producer until G incorporates and validates it. Runtime dependencies are unpinned upstream ranges, and no image recipe is claimed reproducible yet.
