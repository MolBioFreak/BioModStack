# Family MSA settings coverage (incremental)

The request owner's `AlignmentRequest.model_json_schema()` is served at `/api/family-msa/settings-schema`; the editor derives fields from it when available. The legacy editor fields and defaults remain as an offline/failed-discovery fallback, so this is not yet a single-source implementation under all conditions. The schema inventories accepted BMS settings, not every upstream option or a proof of native behavior.

Inspected against the scratch CPU SIF: MAFFT 7.525 `--help`, FAMSA 2.5.2 `-help`, MUSCLE 5.3 `-h`, TWILIGHT 0.3.0 `-h`. For the existing full-family alignment modes, this increment adds MAFFT E-INS-i, `--op` and `--ep`; FAMSA `-r`, `-sm`, `-go`, `-ge`, `-tgo`, `-tge`, `-dist`, `-gsd`, `-gsl`, `-dgr`, `-dgo`, `-dsp`; TWILIGHT `--length-deviation`, `--max-ambig`, `--max-len`, `--min-len`, `--write-filtered`, `--write-prune`, `--check`. Existing MUSCLE align/Super5, permutation, perturbation and ensemble controls were retained.

Known unsupported items from those help surfaces: MAFFT arbitrary `--retree` and `--maxiterate`, `--reorder`, `--quiet`, `--clustalout`, `--dash` and additional CLI options beyond its brief help; FAMSA imported guide tree, profile-profile input, `-gt_export`, `-dist_export`, `-square_matrix`, `-pid`, `-gz`, `-gz_lev`, `-v`; MUSCLE resampling, dispersion, max-CC, EFA conversion/explosion, confidence and related `-maxgapfract`, `-minconf`, `-html`, `-jalview`; TWILIGHT merge/add inputs, `--temp-dir`, `--keep-temp`, `--compress`, `--overwrite`, custom `--matrix`, `--blosum`, `--verbose`, non-accurate mode. Help/version flags are not request settings. Some are distinct workflows or output formats rather than missing controls for approved full-family modes. This list is not an exhaustive audit of MAFFT's complete upstream CLI or hidden/native source options; full source-grounded inventory remains open.

The optional native probe exercises one nondefault combination per engine; it does not qualify every option, all supported molecule types, every combination, actual output semantics of auxiliary TWILIGHT files, or scientific accuracy. No observations were turned into execution or success gates. The editor uses legacy controls if schema discovery fails; typed browser transport and real HTTP persistence must be assessed separately.
